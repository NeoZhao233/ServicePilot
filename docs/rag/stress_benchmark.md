# 自纠错 RAG：非饱和检索压力集（离线）

旧的 24 题在线 B0 Recall@5=100%，不足以观察补检索收益。本轮另建 100 题固定集合，原 24 题和原在线结果仍保留。**新结果是无网络的检索测量，不是 B0/B3 在线对照，也不是任务完成率。**

## 样本与口径

- 政策源为 `data/policies.json` 的 37 条政策；每题需 1–4 条政策。100 条中文场景由人工编写，其中单政策 37、双政策 36、三政策 20、四政策 7；没有复用旧 24 题的原文。
- 标注在 `evaluations/rag_stress_cases.json`，生成脚本固定政策源 SHA256 并校验题目唯一性。问题与标注由同一作者编写，尚无独立复核或真实用户日志，因此只能用作合成压力测试，不能外推线上流量准确率。
- Macro Recall@K：每题找到的必需政策数 / 该题全部必需政策数，再对全部题平均。All-Evidence@K：该题所有必需政策都在 Top‑K 中。Any-Evidence@K：至少找到一条。只在必需政策数不超过 K 的题上计算 All-Evidence@K；四政策题不进入 Top‑3 的这个分母。
- BGE 本地嵌入模型为 `BAAI/bge-small-zh-v1.5`；高级检索使用 BM25、BGE、查询改写及启发式排序。`pre_rerank_candidate_pool` 是进入模型重排前的候选全集。整个运行没有 DeepSeek 调用，不能称其为历史在线 B0。

## 结果

| 检索器 | Macro Recall@3 | All-Evidence@3 | Macro Recall@5 | All-Evidence@5 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 0.9050 | 75/93 = 80.6% | 0.9733 | 93/100 = 93% |
| BGE 向量 | 0.8850 | 71/93 = 76.3% | 0.9525 | 87/100 = 87% |
| BGE+BM25 RRF | 0.9250 | 80/93 = 86.0% | 0.9825 | 95/100 = 95% |
| BGE+BM25+改写+启发式排序 | 0.8908 | 72/93 = 77.4% | 0.9717 | 92/100 = 92% |

最后一行的 Top‑3 All-Evidence 95% Wilson 参考区间约为 67.9%–84.7%；Top‑5 为 85.0%–95.9%。这是把人工编写题目暂作独立随机样本时的数学参考，实际不满足随机抽样假设，**不能视作线上置信区间**。所有方法的 Any-Evidence@3/@5 均为 100%，所以“至少找到一条”的命中率在这个小政策库里仍无区分力。

最后一行按复杂度拆开：单政策题 Top‑3 找齐 37/37；双政策 28/36；三政策 7/20；四政策题因容量限制不计 All-Evidence@3，其 Macro Recall@3 为 0.6786。Top‑5 找齐分别为 37/37、34/36、16/20、5/7。高级检索的重排前候选全集 99/100 找齐，说明多数遗漏发生在候选排序/截断阶段；剩余 1 题连候选也缺，才是更直接的自然补检索压力点。

为让后续 B3 纠错测试有足够的“初始缺证据”题，结果文件还冻结了 63 个多政策初始证据 fixture：8 题原始 Top‑5 自然缺证据，另 55 题从已找齐的 Top‑5 中受控移除一条关键政策。两类分开记录，绝不把受控移除造成的缺失当作自然 B0 失败，也不把待恢复目标计为已恢复。

## 下一步在线对照所需数据

同一批题必须分别运行冻结配置 B0 与 B3，记录初始候选、重排后 Top‑3/Top‑5、充分性判断、补检索查询、每轮新增政策、最后证据集、失败/截断、模型调用量和延迟。针对可补救遗漏报告按题配对的 Recall 与 All-Evidence 差值，另单列“初始缺证据”子集的恢复率；不允许仅选成功补回的题作为分母。完成率需要另有独立标注的最终答复或售后任务判定，不能从检索命中推导。当前这些 **B3 在线指标、真实任务完成率均未测得**。

仅对 100 题做一次 B0 重排和一次 B3 评分/充分性判断，理论起点约为 300 次外部模型调用，触发纠错还会增加请求；需先确定新的明确调用上限和费用预算。过去实验已用 81/95 次授权额度，剩余 14 次不足以支持该规模的成对对照。上线或论文级结论还应补充真实用户抽样、独立双人标注与分歧裁决，并固定盲测集，避免依据本次离线错题反复调参后再次评价同集。

复现命令（完全离线）：

```sh
HF_HUB_OFFLINE=1 PYTHONPATH=src .venv/bin/python scripts/evaluate_rag_stress.py \
  --output evaluations/results/rag_stress/offline.json
```

原始逐题预测、漏掉的政策、各切片分母及源文件哈希保存在 `evaluations/results/rag_stress/offline.json`。
