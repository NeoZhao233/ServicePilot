## 请求预算与复现

预检占 1 次。首次按剩余 23 次预算执行；用户再次回复“继续”后，将含预检的总上限调整为 25 次，再续跑最后 1 题。最终评测 24/24 题，含预检 25 次，零失败、零重试。脚本没有重试；模型调用前保存请求计数，避免进程意外退出丢失已花费次数。在线结果文件拒绝意外覆盖，只允许从干净的预算停止状态显式续跑，不自动重复失败请求。

脚本记录调用原始重排器前的完整候选顺序、政策 ID、分数、内容哈希，以及返回用量、脱敏 Span、排名、检索和重排耗时。保持 limit=5，K=3 指标从同次结果前三名计算；模型请求格式不使用 limit，两个指标没有重复付费调用。规则对照使用完全相同初始候选的前五/前三名，不另外召回。

```sh
# 涉及真实调用；使用者先确认剩余授权预算。已有结果文件不能覆盖。
PYTHONPATH=src .venv/bin/python scripts/jev_stage1_online.py \
  --allow-network --max-calls 23 --env-file .env \
  --output evaluations/results/jev_stage1/b0_online.json
```

`.env` 仅在显式指定时读取，密钥不写入结果。只对冻结数据与政策及生产检索源码的 SHA256 匹配版本执行，原值见 `offline_profile.json`。后续异机复现需匹配模型文件指纹；这次只做一次在线遍历，未估计模型多次运行方差。

## 指标解释

API 返回实际输入/输出 Token，输出用量可能包含 reasoning_tokens 的计数，不采集隐藏推理文本。供应商未返回实际费用，费用保持 null；不能将输出 Token 乘以未核实价格并声称是实际账单。调用失败后原检索器仍可能返回规则降级结果，脚本会保留故障证据并停止，且不计为成功的模型评测。

耗时是 `search()` 完整检索调用，不含 HTTP/意图分类/客服答案生成；本项目尚无统一模型最终生成节点。最终答案正确率、无依据承诺次数、充分性准确率仍未评测，不用检索召回率代替。
